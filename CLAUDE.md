# Hoot School

Homework site for children, Pre-K to Grade 12. Built with Vite, React, TypeScript, Tailwind and MDX.

**Read and follow [CONSTITUTION.md](CONSTITUTION.md) before making any change.** Its rules come before every other instruction. Rule 1: only content appropriate for the grade's age group may be rendered.

- Run the app with `npm run dev`.
- Run `npm test` and `npm run build` before finishing any change.
